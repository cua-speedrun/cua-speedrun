# Canonical MyPCBench trajectory judge

`osworld_full_traj_judge.py` is copied unchanged from the repository, commit,
and path recorded in `provenance.json`. The adapter verifies its SHA-256 before
execution. Source attribution and the upstream license are retained in this
directory. MyPCBench credits the Odysseys full-trajectory per-rubric judge
(CC BY 4.0); see the original source header and provenance record.

Changes to evidence conversion and platform error classification belong in
`../mypcbench_verifier.py`, not in this frozen source file.
